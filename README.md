# CIA Sender (Android)
Envía .cia a FBI (3DS) por WiFi, igual que Boop.

## Sacar el APK sin instalar nada
1. Crea un repositorio en GitHub y sube todo el contenido de esta carpeta.
2. Pestaña Actions -> "Build APK" (se lanza solo al subir; o "Run workflow").
3. Al terminar, descarga el artefacto "CiaSender-APK" (zip con el .apk).
4. Instálalo en el móvil (permitir orígenes desconocidos).

## Uso
1. En la 3DS: FBI -> Remote Install -> Receive URLs over the network.
2. En la app: escribe la IP que muestra la 3DS (se guarda), añade los CIA y pulsa Enviar.
